# 🏢 Sistema ERP – Taller de Arquitectura de Software

Este repositorio contiene el desarrollo del **taller de arquitectura de software**, cuyo objetivo es diseñar la arquitectura de un **sistema ERP empresarial** utilizando el modelo **arc42**.

El sistema ERP propuesto permite gestionar de manera integrada los procesos de:

- Compras  
- Facturación  
- Inventario y costos  
- Activos fijos  
- Gestión de empleados  
- Reportes ejecutivos (EIS)

## 🧩 Modelo de Arquitectura

La arquitectura del sistema está basada en:

- Arquitectura en capas  
- Aplicación web  
- Backend con API REST  
- Base de datos relacional  

Se busca lograr un sistema **modular, escalable y fácil de mantener**.
